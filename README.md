# Machine Learning with Python

Notebooks, datasets, and practice exercises from a Machine Learning with Python course I completed. The course was very useful to me, so I'm sharing the materials in case they help others learning the same topics.

## Original Course

This repository is based on the **Machine Learning with Python** course created by **Jadi** and the **Maktabkhooneh** team. All credit for the course content goes to them.

To watch the course videos, visit the original course page:
[Machine Learning with Python on Maktabkhooneh](https://maktabkhooneh.org/lms/course/%DB%8C%D8%A7%D8%AF%DA%AF%DB%8C%D8%B1%DB%8C-%D9%85%D8%A7%D8%B4%DB%8C%D9%86-%D9%BE%D8%A7%DB%8C%D8%AA%D9%88%D9%86-mk1318/unit/42500/)

This repository is an unofficial collection of the notebooks, datasets, and practice exercises I worked through while taking the course. It is not affiliated with or endorsed by the course authors.

## Repository Structure

| Directory | Contents |
|-----------|----------|
| `1)Introduction` | Notebooks on the core data libraries: NumPy, Pandas, and Matplotlib. |
| `2)Regression` | Simple, multiple, polynomial, and non-linear regression, using a CO2 emissions dataset. |
| `3)Classification` | Decision Trees, K-Nearest Neighbors (KNN), Logistic Regression, and Support Vector Machines (SVM). Each algorithm has its own subfolder with a notebook and dataset. |
| `4)Clustering` | K-Means, Hierarchical clustering, and DBSCAN, each with its own notebook and dataset. |
| `5)Recommendation Systems` | Content-based and collaborative-filtering recommenders, using a movies dataset. |
| `6)Practices` | Three hands-on practice projects (`MaktabKhone_ML_Practice_1` to `3`) covering house prices, heart disease, and customer data. |
| `7)Books` | Reference book for the course (not included in the repository). |
| `requirements.txt` | Python dependencies needed to run the notebooks. |

## Topics Covered

- **Data basics:** NumPy, Pandas, Matplotlib
- **Regression:** simple, multiple, polynomial, non-linear
- **Classification:** Decision Trees, KNN, Logistic Regression, SVM
- **Clustering:** K-Means, Hierarchical, DBSCAN
- **Recommender systems:** content-based, collaborative filtering

## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd MachineLearning_with_Python
   ```
2. Create and activate an environment (conda example):
   ```bash
   conda create -n ml-course python=3.10
   conda activate ml-course
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Launch Jupyter and open any notebook:
   ```bash
   jupyter notebook
   ```

Each topic folder is self-contained: the notebook and the dataset it uses sit side by side, so you can run any of them independently.
